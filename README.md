# moodcafe
A mood-based wellness website that serves you a menu to  feel better. 
College group project by anshal ,swapna and sirat .
## about
A visitor shares their mood, answers five gentle  questions , and gets a personal 
report with ideas for meditation, exercise, music,food. if stress is high.
## features
- Mood check-in form(6 moods +5 questions) with validation
- stress score: low(5-9),medium(10-14),high(+15)
- personal relax menu that changes by stress level 
- 1-minute animated breathing exercise
- "thought for today" quote button 
## pages
index.html . survey.html  .  result.html  .    tips.html  .  help.html
## Built with 
HTML5,CSS,JAVASCRIPT,GOOGLE FONTS(POPPINS),localstorage
## Run locally 
download the files and open "index.html" in your browser.
